# 기술 설명

## 파일 구조

- 데이터 파일 대부분(`.BIN`, `.RSL`)은 **RMHG** 컨테이너입니다. 노드가 트리 형태로 중첩되고, 각 항목은 오프셋·크기를 가집니다(`tools/py/rmhg.py`).
- 상당수 파일은 자체 **LZ** 압축입니다. 머리는 `원래 크기(4) · 압축 크기(4) · 이스케이프 바이트(1)`이고, 이스케이프 뒤에 길이·거리를 담습니다(`tools/py/lz.py`, `tools/c/nmhlz.c`).
- 문장은 **GDLG** 블록에 들어 있고, 바로 뒤 형제 노드가 그 문장에 쓰는 글자만 담은 글꼴 **STRIMAG2**입니다.
  - GDLG v0: UTF-16 문장. 글꼴은 글자 코드 순 선형 표(`gdlg.py`, `strimag.py`).
  - GDLG v1: Shift-JIS 문장(이벤트 문장). 한글은 비어 있는 Shift-JIS 코드에 대응시켜 글꼴에 넣습니다(`gdlg1.py`, `sjmap.py`).
  - 해시형 STRIMAG: 문장 표와 글꼴이 한 블록에 있는 형식. 세이브 메시지와 `main.dol`의 시스템 메시지가 이 형식입니다(`strimag_h.py`, `hbuild.py`).
- 글꼴 이미지는 GCT/TPL 계열 4비트 텍스처이며, 원본 글꼴 이름별로 나눔스퀘어네오 굵기와 크기 비율을 정해 다시 그립니다(`fontgen.py`).

## 주의한 점

### 압축 거리 제한

게임의 압축 해제 루틴은 거리 참조를 0x100000(1MB)까지만 제대로 처리합니다. 원본 압축 데이터도 최대 거리가 정확히 0x100000입니다. 처음에는 16MB까지 참조하도록 압축해 일부 파일에서 문제가 생겼고, v1.1에서 원본과 같은 한계로 맞췄습니다.

### 파일 안 배치 유지

모텔 스테이지(`STG3001.BIN`)는 노드 위치가 원본과 달라지면 같은 파일을 끝없이 다시 읽으며 로딩이 멈췄습니다. 그래서 `inplace.py`는 바뀐 노드를 원래 자리에 넣고 남는 칸을 0으로 채운 뒤 항목 크기만 새 값으로 고칩니다. 원래 자리보다 커진 노드만 뒤쪽을 밀어 넣습니다.

### 디스크 배치 유지

`inject.py`는 복호화한 디스크에 바뀐 파일만 넣습니다. 크기가 같거나 작으면 원래 자리, 커지면 빈 영역으로 옮기고 FST를 고칩니다. 그 뒤 H0~H3 해시를 다시 계산하고 암호화한 다음, 쓰이지 않는 해시 그룹은 원본 암호화 데이터로 되돌려 xdelta 크기를 줄입니다.

## 검증

- `tools/py/integ.py`: 패치 파일과 원본의 RMHG 구조 비교
- `tools/py/lzstat.py`: 압축 데이터의 최대 거리·길이 통계
- `tools/py/emu.py`, `auto.py`, `tomotel.sh`: Dolphin을 백그라운드로 띄워 가상 컨트롤러(DSU)로 조작하고 프레임 덤프로 화면을 확인
