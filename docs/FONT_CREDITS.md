# 글꼴

| 글꼴 | 쓰인 곳 | 배포처 |
| --- | --- | --- |
| 나눔스퀘어네오 (bRg·cBd·dEb) | 자막·대화·시스템 메시지 글꼴 이미지, 스트랩 주의 화면 | 네이버 |
| 서울한강체 EB | 데스매치 「격파」 | 서울특별시 |

원본 글꼴별 대응(`tools/py/fontgen.py`)은 다음과 같습니다.
- NewCinemaAStd-D(자막), DotGothic12Std-M, BT 12G LCD Bold → 나눔스퀘어네오 cBd
- DF 계열 W6 장식체(데스매치·세이브 화면) → 나눔스퀘어네오 dEb
- Basic_E_Regular → 나눔스퀘어네오 bRg

글꼴 파일은 저장소에 넣지 않았습니다. 재빌드할 때 저장소 최상위에 둡니다.
